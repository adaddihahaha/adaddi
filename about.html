About Solar Savings

Solar Savings is a focused collection of calculators and utilities for electricity and solar planning. The site groups tools that help estimate bills, model payback, and size small rooftop systems.

Our goals

  • Provide clear, practical calculators to estimate savings and payback.
  • Run interactive tools in the browser (note: tools are not guaranteed to run offline and some features may require network access).
  • Expand the toolbox with utilities such as an Appliances Electricity Calculator, a system sizing helper, and comparison charts.

Planned features

Next: an Appliances Electricity Calculator (estimate kWh per appliance and monthly cost). Future updates will add guides for system selection and installer comparison.
